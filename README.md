# SA-MP Gamemode on GitHub Codespaces

Repository ini digunakan untuk menjalankan **SA-MP (San Andreas Multiplayer) Gamemode** melalui **GitHub Codespaces**.

Dengan menggunakan Codespaces, server SA-MP dapat dijalankan langsung dari environment Linux berbasis cloud tanpa harus menjalankan server di PC sendiri.
